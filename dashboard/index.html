How the value is built

Every multiple comes from the snapshot itself: the median market-cap-per-TVL of the protocols in that category whose token already trades, shrunk toward the global median when the category has fewer than three traded protocols. A category with fewer than three takes the global median outright. No protocol name is ever special-cased — the same function scores every row.

“Pre-token” means the snapshot's record carries no token for the protocol. It is not proof the protocol has none. Protocols the house's rule leaves out as wrapped, staked or bridged products of a token that already trades — and the arms of a protocol that already has one — are not ranked.

Live tokens — the market's own values

These protocols already trade. The board never ranks them; it uses them as comparables. The ratio column is the market cap per dollar of TVL the model learns from.
